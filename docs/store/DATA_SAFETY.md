# Play Console 데이터 보안 — 화면 순서대로

> 바로 가져오기: [data_safety_import.csv](data_safety_import.csv) (Play Console 데이터 보안 → 가져오기 · 내보내기 → CSV 가져오기). 아래 표와 같은 내용.

Play Console → 앱 콘텐츠 → 데이터 보안. 위에서부터 화면에 나오는 순서 그대로 적었다.

## 1단계: 데이터 수집 및 보안

| 화면 질문 | 답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 앱에서 수집하는 모든 사용자 데이터가 전송 중에 암호화되나요? | **예** (모두 HTTPS · Firebase) |
| 앱에서 지원하는 계정 생성 방법 | **OAuth** 하나 (구글 · 카카오 로그인. 게스트는 자동 익명 계정이라 고르지 않음) |
| 계정 삭제 요청 URL | `https://graviton94.github.io/mintandfriends/privacy/#delete` |
| 사용자가 데이터 삭제를 요청할 수 있는 방편을 제공하나요? | **예** (같은 삭제 안내 주소) |
| 독립적인 보안 검토 | 아니요 |
| 앱 외부에서 만든 계정으로 로그인 | 아니요 (구글 · 카카오는 위 OAuth 로 이미 답함) |

## 2단계: 데이터 유형 고르기

| 분류 | 체크할 항목 |
|---|---|
| 개인 정보 | **이름**, **사용자 ID** |
| 위치 | **대략적인 위치** |
| 앱 정보 및 성능 | **진단** (AdMob SDK 가 모음) |
| 앱 활동 | **앱 상호작용**, **기타 사용자 제작 콘텐츠** (정원 · 정원 이름) |
| 기기 또는 기타 ID | **기기 또는 기타 ID** |
| 나머지 (금융 · 건강 · 메시지 · 사진 · 오디오 · 파일 · 캘린더 · 연락처 · 웹 방문) | 없음 |

## 3단계: 항목마다 같은 질문 4개 (① 수집 · 공유 ② 임시 처리 ③ 필수 / 선택 ④ 목적)

| 항목 | ① | ② 임시 | ③ | ④ 수집 목적 | ④ 공유 목적 |
|---|---|---|---|---|---|
| 이름 | 수집 | 아니요 | 선택 가능 | 앱 기능, 계정 관리 | — |
| 사용자 ID | 수집 | 아니요 | 필수 | 앱 기능, 계정 관리 | — |
| 대략적인 위치 | 수집 + 공유 | 아니요 | 필수 | 광고 또는 마케팅, 애널리틱스, 사기 예방 · 보안 · 규정 준수 | 같음 |
| 진단 | 수집 + 공유 | 아니요 | 필수 | 애널리틱스, 사기 예방 · 보안 · 규정 준수 | 같음 |
| 앱 상호작용 | 수집 + 공유 | 아니요 | 필수 | 앱 기능, 애널리틱스, 광고 또는 마케팅, 사기 예방 · 보안 · 규정 준수 | 광고 또는 마케팅, 애널리틱스, 사기 예방 · 보안 · 규정 준수 |
| 기타 사용자 제작 콘텐츠 | 수집 | 아니요 | 필수 | 앱 기능 | — |
| 기기 또는 기타 ID | 수집 + 공유 | 아니요 | 필수 | 광고 또는 마케팅, 애널리틱스, 사기 예방 · 보안 · 규정 준수 | 같음 |

근거:
- **대략적인 위치**: 앱이 직접 위치를 쓰지 않는다. AdMob 이 IP로 광고 지역을 정하고 Google 로 보낸다 → 공유.
- **이름**: 친구에게 보이는 정원 이름을 직접 입력하는 경우에만 → 선택.
- **사용자 ID**: 게스트도 시작할 때 Firebase 익명 계정 ID가 자동으로 생긴다 → 필수. 구글 · 카카오 회원 번호도 여기.
- **앱 상호작용**: 게임 진행 · 정원 · 친구 목록(클라우드 저장)과 Firebase Analytics 이벤트. 분석은 끌 수 없다 → 필수.
- **기기 또는 기타 ID**: 광고 ID(AdMob) · 앱 인스턴스 ID(Analytics) → 광고 쪽은 공유.
- **진단 · 앱 상호작용 · 위치 · 기기 ID 의 공유 목적**: Google 이 밝힌 AdMob SDK 수집 항목 · 용도(광고, 애널리틱스, 사기 방지)를 따름.
- **기타 사용자 제작 콘텐츠**: 내가 꾸민 정원 · 정원 이름이 친구에게 보이도록 서버에 저장 → 필수 (게스트 포함).
- Firebase(Google)처럼 우리 대신 데이터를 처리하는 서비스 제공업체로 보내는 것은 Play 기준 '공유'가 아니다. 공유 ✔ 는 광고 네트워크(AdMob)로 가는 것만.
