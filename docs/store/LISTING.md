## 한국어 (기본)
- 앱 이름 (17자): `민트앤프렌즈: 방치형 머지 힐링`
- 간단한 설명 (51자): `꽃과 간식을 합쳐 동물 친구들의 부탁을 들어주고, 허브 정원을 꾸미는 귀여운 힐링 머지 게임`
- 자세한 설명 초안:

> 토끼 민트와 허브 친구들이 사는 작은 정원으로 오세요.
>
> 🌱 합치기만 하면 끝 — 같은 꽃과 간식을 끌어다 합치면 더 예쁜 아이템이 돼요.
> 🐰 친구들의 부탁 — 세이지, 바질, 라벤더… 친구들이 원하는 아이템을 전해 주고 별을 모아요.
> 🏡 정원 꾸미기 — 별로 벤치, 분수, 온실, 관람차까지 하나씩 설치하면 새 친구가 놀러 와요.
> 🌙 방치형 — 앱을 꺼 둬도 정원은 자라요. 돌아오면 쌓인 코인을 받으세요.
> 💗 호감도 — 부탁을 들어줄수록 친구들이 도와줘요.
>
> 바쁜 하루 틈틈이, 머리 비우고 편하게 즐기는 힐링 게임입니다.
