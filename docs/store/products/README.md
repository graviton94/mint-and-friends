# Play Console 인앱 상품 이미지

Play Console → 수익 창출 → 제품 → 각 상품의 이미지. 규격: 32비트 PNG(투명 배경) · 1:1 · 512×512 · 상품마다 다른 그림 · 글자 · 홍보 문구 · 로고 없음.

|---|---|---|

| `gems_430.png` | 다이아 바구니 (430) | 다이아 바구니 |
| `gems_900.png` | 다이아 주머니 (900) | 다이아 주머니 |
| `gems_2000.png` | 다이아 상자 (2,000) | 나무 상자 |
| `gems_6000.png` | 다이아 보물 상자 (6,000) | 보물 상자 |
| `gems_14000.png` | 다이아 보물단지 (14,000) | 보물단지 |
| `starter_2900.png` | 새싹 정원 패키지 | 민트 + 선물 상자 |
| `garden_pass_1m.png` | 정원 패스 (구독) | 정원 패스 티켓 |
