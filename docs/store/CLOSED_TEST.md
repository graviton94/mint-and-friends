# 비공개 테스트 준비 (Play Console)

민트앤프렌즈 · 패키지 `io.github.graviton94.mintandfriends`
필요한 문구 · 그림 · 답안은 모두 [LISTING.md](LISTING.md) 와 `docs/store/` 에 있다. 아래 순서대로 하면 된다.

## 0. 올릴 파일 (AAB)

비공개 테스트는 Play 서명용 **AAB** 가 필요하다 (지금 Releases 의 APK 는 사이드로드용).
→ 등록 준비가 되면 Claude 에게 "AAB 빌드해줘" 라고 하면 GitHub Actions 로 업로드 키 서명 AAB 를 만든다
(`ANDROID_UPLOAD_*` 비밀값은 이미 등록됨).

1. Play Console → **앱 만들기**: 이름 `Mint & Friends: Merge Garden`, 기본 언어 **English (United States)**, **게임**, **무료**

결제 프로필(판매자 계정)이 먼저 필요하다.
- **관리형 제품** 7개: `starter_2900` ₩2,900 (새싹 정원 패키지, 1회) · `gems_100` ₩1,900 · `gems_430` ₩5,900 · `gems_900` ₩9,900 · `gems_2000` ₩19,000 · `gems_6000` ₩38,000 · `gems_14000` ₩79,000
- **정기 결제** 1개: `garden_pass_1m` 월 ₩5,900 (정원 패스: 광고 제거 · 매일 다이아 10 · 별 부탁 +2 · 보관 칸 2)

## 5. 광고 (AdMob)
1. AdMob 에 앱 추가(스토어 등록 전이면 "미게시 앱") → **보상형 광고 단위** 1개
2. 앱 ID · 광고 단위 ID 를 Claude 에게 전달 → GitHub 비밀값으로 연결 (지금은 테스트 광고)

## 6. Firebase 원격 구성
Firebase 콘솔 → Remote Config → 아래 8개 키를 지금 값 그대로 추가 후 게시 (이후 여기서 조정):
`energy_regen_seconds` 150 · `energy_ad_amount` 20 · `refill_base` 60 · `refill_step` 30 · `refill_max` 150 · `rescue_chance` 0.25 · `market_price_base` 10 · `area_star_scale` 1.0

## 6-1. Play 앱 서명 키 등록 (첫 AAB 업로드 직후 꼭)
Play 에 올린 앱은 Google 이 **앱 서명 키**로 다시 서명한다. 이 키의 지문을 Firebase · 카카오에 넣지 않으면
**Play 에서 받은 앱에서만 구글 · 카카오 로그인이 실패**한다 (사이드로드 APK 는 업로드 키라 문제없음).
1. Play Console → 설정 → **앱 무결성** → 앱 서명 → "앱 서명 키 인증서"의 **SHA-1 · SHA-256** 복사
2. Firebase 콘솔 → 프로젝트 설정 → Android 앱 → **디지털 지문 추가** → SHA-1 · SHA-256 둘 다
   → 새 `google-services.json` 은 받지 않아도 됨 (지문은 서버 쪽 설정)
3. 카카오: SHA-1 을 Claude 에게 주면 **키 해시**(Base64)로 바꿔 줌 → Kakao Developers → 내 애플리케이션 → 플랫폼 → Android → 키 해시 추가
   (직접 바꾸려면: `echo <SHA1 콜론 포함> | xxd -r -p | openssl base64`)

## 7. 비공개 테스트 트랙
1. 테스트 → **비공개 테스트** → 트랙 만들기 → 테스터: 이메일 목록(Google 그룹 가능)
2. 새 버전 만들기 → AAB 업로드 → 출시 노트(아래) → 검토 제출
3. 개인 개발자 계정: **테스터 12명 이상이 14일 연속 참여**해야 프로덕션 신청 가능
4. 승인되면 "웹에서 참여" 링크를 테스터에게 공유

출시 노트 예:
```
민트앤프렌즈 비공개 테스트에 와 주셔서 고마워요!
합치기 · 부탁 · 정원 꾸미기 · 친구 · 출석까지 모두 들어 있어요.
불편한 점이나 버그는 앱 설정의 문의 메일이나 테스트 그룹에 알려 주세요.
```

## 8. 테스터 안내문 (그대로 보내도 됨)

```
🌱 민트앤프렌즈 비공개 테스트 안내

1) 아래 링크에서 '테스터 되기'를 누르고, Play 스토어에서 설치해 주세요.
   [웹에서 참여 링크]
2) 14일 동안 하루에 한 번 이상 들어와 주세요. (출석 선물이 있어요!)
3) 이런 걸 알려 주시면 큰 도움이 돼요:
   - 막히거나 헷갈렸던 곳 (어디서, 무엇을 하려다)
   - 너무 쉽거나 어려운 곳, 지루했던 곳
   - 이상하게 보이는 화면 (스크린샷 환영)
   - 앱이 꺼지거나 멈춘 순간
4) 결제는 테스트 계정이라 실제로 청구되지 않아요.
5) 테스트 진행 상황은 저장되지만, 정식 출시 때 초기화될 수 있어요.

고마워요! 🐰
```
