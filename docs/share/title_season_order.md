# 발주서: 계절별 시작 화면 (8장)

첨부 기준 그림 3장 (docs/share/title_season_ref/):
- `ref_bg.webp` — 지금 배경 (1080×1920)
- `ref_fg_on_white.png` — 지금 앞쪽 그림 (1080×382, 실제는 투명 배경)
- `ref_combined.png` — 둘을 합친 실제 화면

## 공통 규칙 (8장 모두)
- 그림체: 첨부 그림과 똑같이. 파스텔 · 굵은 갈색 외곽선 · 스티커 같은 귀여운 캐주얼 게임 그림.
- **구도 · 시점 · 물체 위치를 첨부 그림과 똑같이 유지**하고, 계절 요소만 바꾼다.
- 글자 · 로고 · 숫자 · 워터마크 넣지 말 것 (로고는 게임이 따로 얹는다).
- 화면 위쪽 1/4(하늘)은 로고 자리라 복잡한 물체를 두지 말 것.

## 배경 4장 — 1080×1920, 세로, 불투명
첨부 `ref_bg`와 같은 구도: 위 하늘 · 오른쪽 빨간 지붕 오두막 · 등불 · 하얀 울타리 · 가운데로 휘어 들어오는 흙길 · 초록 언덕.
하단 약 20%는 앞쪽 그림이 덮으므로 단순하게.

1. **봄** `bg_spring` — 연분홍 벚꽃나무가 양옆 언덕에, 하늘에 꽃잎 몇 장, 길가에 튤립 · 데이지, 오두막 지붕에 꽃 덩굴. 밝은 하늘색 하늘.
2. **여름** `bg_summer` — 짙은 초록 나무, 쨍한 파란 하늘과 뭉게구름, 울타리 옆 해바라기, 오두막 창가에 풍경(바람종) 하나. 햇살 느낌.
3. **가을** `bg_autumn` — 주황 · 빨강 단풍 나무, 노을빛 살구색 하늘, 길 위에 낙엽, 오두막 앞에 호박 2~3개.
4. **겨울** `bg_winter` — 눈 덮인 지붕 · 울타리 · 언덕, 연한 하늘색 하늘에 작은 눈송이, 창에 따뜻한 노란 불빛, 굴뚝 연기 조금, 길가에 작은 눈사람.

## 앞쪽 그림 4장 — 1080×382, 가로, **투명 배경(PNG)**
첨부 `ref_fg`와 같은 구도 · 같은 자세: 왼쪽부터 곰(밀짚모자) · 고양이 · 가운데 아기 토끼 민트(초록 멜빵) · 판다(찻잔) · 오리(파란 스카프), 아래에 꽃 덤불.
**친구들의 자세 · 표정 · 위치는 바꾸지 말고 옷과 소품만 계절에 맞게**, 덤불의 꽃만 계절 것으로.

5. **봄** `fg_spring` — 머리에 작은 꽃 화관 · 꽃핀, 덤불은 튤립 · 벚꽃.
6. **여름** `fg_summer` — 밀짚모자 · 선글라스 · 수박 조각 같은 여름 소품, 덤불은 해바라기 · 수국.
7. **가을** `fg_autumn` — 니트 목도리 · 베레모 · 도토리 · 사과, 덤불은 단풍잎 · 국화 · 작은 호박.
8. **겨울** `fg_winter` — 털모자 · 목도리 · 귀마개, 덤불 위에 눈 · 빨간 열매 · 포인세티아 대신 동백꽃.

## 납품
- 배경: PNG 또는 WebP, 1080×1920.
- 앞쪽: PNG(투명), 1080×382. 친구들 발끝 · 덤불이 아래 끝에 닿게.
- 파일 이름은 위 `bg_spring` 등으로.
