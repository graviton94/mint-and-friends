# 비축 콘텐츠 (정식 출시 뒤 업데이트용, D-055)

여기 그림은 **앱에 들어가지 않는다** (`pubspec.yaml` 의 assets 는 `assets/` 만 등록).
업데이트를 풀 때 `art/` 아래를 `assets/art/` 의 같은 경로로 옮기고, 구역 · 친구 · 장식 설정을 코드에 붙인 뒤 시뮬레이터로 확인한다.

| 폴더 | 업데이트 | 내용 | 상태 |
|---|---|---|---|
| `u1_orchard` | 정식 출시 뒤 **첫 업데이트** | 7구역 사과 과수원 (배경 · 장식 8종 × 기본/고급/특별/봄/여름/가을/겨울 · 랜드마크 빨간 헛간 4단계) + 새 친구 캐모마일(양) 자세 4종 + 사계절 의상 | 그림 완료 |
| `u2_mushroom_forest` | 두 번째 업데이트 | 8구역 버섯 숲 (배경 · 장식 8종 × 7디자인 · 랜드마크 버섯 집 4단계) + 새 친구 타임(아기 사슴) 자세 4종 + 사계절 의상 | 그림 완료 |
| `u3_cloud_garden` | 세 번째 업데이트 | 9구역 구름 정원 (배경 · 장식 8종 × 7디자인 · 랜드마크 열기구 정류장 4단계) + 새 친구 레몬밤(아기 부엉이) 자세 4종 + 사계절 의상 | 그림 완료 |
| `u4_bamboo_garden` | 네 번째 업데이트 | 10구역 대나무 찻집 (배경 · 장식 8종 × 7디자인 · 랜드마크 정자 탑 4단계) + 새 친구 진저(레서판다) 자세 4종 + 사계절 의상 | 그림 완료. 배경에 석등 · 다과상이 그려져 있어 같은 장식과 겹칠 수 있음 → 넣을 때 배치 확인 |
| `u5_candy_village` | 다섯 번째 업데이트 | 11구역 과자 마을 (배경 · 장식 8종 × 7디자인 · 랜드마크 과자 성 4단계) + 새 친구 히비스커스(아기 돼지, 파일 id `malang`) 자세 4종 + 사계절 의상 | 그림 완료. 기본 시트의 기쁨 자세에는 반짝 표시가 없음 (가을 · 겨울 의상에는 있음) |
| `u6_hot_spring` | 여섯 번째 업데이트 | 12구역 온천 마을 (배경 · 장식 8종 × 7디자인 · 랜드마크 목욕탕 4단계) + 새 친구 루이보스(아기 원숭이, 파일 id `dalong`) 자세 4종 + 사계절 의상 | 그림 완료. 겨울 의상은 다시 받은 시트(11-25)로 교체, 모자를 써서 머리 수건은 없음 |

- 구역 엠블럼(7~12)은 `emblems/emblems_7_12.webp` 한 장에서 잘라 각 폴더 `art/icons/area_<구역>.webp` (192px)에 넣었다.
- `sheets/`: 받은 원본 시트 (다시 자를 때)
- `art/`: 잘라 둔 게임용 파일 (WebP, 기존 규격: 장식 384 · 랜드마크 640 · 친구 512 · 배경 1536×1024)
